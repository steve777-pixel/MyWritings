# Self-Writing Works across Different Topics

A repository directed at improving my understanding across various fields, such as science, philosophy, movies, history, etc.
The main goal is to implement writing as the main source of reinforcing learning.

## Table of Contents

1. [Project Overview](#1-project-overview)
2. [Main Objectives](#2-main-objectives)

## 1. Project Overview

Self-Writing Works across Different Topics is a project designed to reinforce learning through writing.

Unlike elementary writing, this writing focuses on deep analysis, research, discussion, and evaluation.

## 2. Main Objectives

- Apply writing to analyze different topics.
- Develop a layered analysis of writing.
- Develop a rich collection of writing database.
- Implement high-quality writing.
- Practice drafting, editing, and polishing.
- Apply concepts learned across different fields to analyse in writing.
